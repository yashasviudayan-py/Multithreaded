Why use it

Protocol without lock-in

Hyper and Tokio provide async I/O; rustls avoids an OpenSSL runtime dependency.

Protection by default

Body limits, per-IP rate limiting, global concurrency limits, secure cookie attributes, and CSRF checks are built into the request path.

Ready to inspect

Structured logs, request IDs, and Prometheus-compatible counters make behavior visible in production.
